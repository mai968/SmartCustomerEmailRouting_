# Smart-Customer-Email-Routing-Process-Optimization
#### An data analytics and machine learning project for customer support email classification and routing optimization.

## Overview

Customer support teams receive many emails about different issues, such as technical problems, product information, billing, and support requests. Manually sorting these emails can take time and make it harder to assign each request to the right team.

**Smart Customer Email Routing & Process Optimization** is an exploratory study on using Machine Learning to automatically classify customer support emails. The study uses **16,338 English-language emails across 10 categories**. TF-IDF is used to convert email text into numerical features, while Linear SVM is used to predict the appropriate category for each email.

The model achieved **72.46% accuracy** on a test set of 1,634 emails. A Power BI dashboard was also created to show email distribution across categories, evaluate model performance, and identify the categories that are often misclassified.

Through this study, I aim to explore how Machine Learning can support email classification and make it easier to assign customer requests to the appropriate teams. However, the model has only been tested on an existing dataset and has not yet been used in a real-world system.
